Build websites instantly using AI directly in VS Code! Just describe what you want and watch your website come to life with a single command.

## Features

- **AI-Powered Generation**: Uses AI to create complete websites based on your description
- **Single Command Workflow**: Just describe what you want - the AI handles the rest
- **Complete HTML/CSS/JS**: Generates full HTML files with embedded CSS and JavaScript
- **Workspace Integration**: Creates files directly in your current VS Code workspace
- **Smart Validation**: Automatically validates and ensures files are created correctly

## Commands

Frontify provides the following commands:

### Frontify: Build Website
- **Command**: `frontify.build`
- **Description**: Build a complete website using AI based on your description
- **Usage**: 
  1. Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
  2. Type "Frontify: Build Website"
  3. Describe your website (e.g., "Create a portfolio with dark mode and animations")
  4. Watch as Frontify generates your complete website!

### Frontify: Setup API Key
- **Command**: `frontify.setup`
- **Description**: Quickly set up your Gemini API key for Frontify
- **Usage**:
  1. Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
  2. Type "Frontify: Setup API Key"
  3. Enter your Gemini API key when prompted

## Setup Instructions

### Method 1: Quick Setup (Recommended)
1. Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
2. Type "Frontify: Setup API Key" and press Enter
3. Enter your Gemini API key when prompted

### Method 2: Manual Setup
1. Get a free API key from [Google AI Studio](https://aistudio.google.com/)
2. Open VS Code Settings (`Ctrl+,` on Windows/Linux or `Cmd+,` on Mac)
3. Search for "Frontify"
4. Enter your API key in the "Frontify: Api Key" field

## Requirements

- **VS Code** version 1.60.0 or higher
- **Internet connection** (for Gemini API calls)
- **Google Gemini API key** (see Setup Instructions above)

## Extension Settings

Frontify adds the following settings to VS Code:

* `frontify.apiKey`: Your Google Gemini API key (required for AI functionality)
